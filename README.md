# Alarme de Sucesso

Dashboard web inicial do Alarme de Sucesso, feito com React, TypeScript e Vite.

## Executar

```powershell
cd .\alarme-sucesso
npm install
npm run dev
```

A tela inicial já inclui alarme ativo, progresso dos desafios, sequência de vitórias e conclusão interativa das tarefas matinais.
